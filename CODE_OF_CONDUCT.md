# Code of Conduct

## Мета

Цей кодекс визначає правила взаємодії учасників проєкту TrustVault.

Усі учасники повинні підтримувати професійну та доброзичливу атмосферу під час обговорення коду, створення Issues та Pull Requests.

## Очікувана поведінка

Учасники повинні:

* ставитися до інших з повагою;
* конструктивно обговорювати технічні питання;
* аргументувати свої пропозиції;
* спокійно сприймати конструктивну критику;
* поважати різні думки та рівень досвіду інших розробників;
* дотримуватися правил GitHub та ліцензії проєкту.

## Неприйнятна поведінка

Не допускаються:

* образи та особисті нападки;
* дискримінація або переслідування;
* погрози;
* навмисна публікація приватної інформації;
* образливі або принизливі коментарі;
* навмисне створення конфліктних ситуацій;
* інші форми непрофесійної поведінки.

## Вирішення конфліктів

Проблемні ситуації повинні вирішуватися шляхом спокійного обговорення.

Якщо порушення правил продовжується, адміністратор репозиторію може закрити Issue або Pull Request та обмежити участь користувача в проєкті.

## Застосування кодексу

Кодекс поведінки поширюється на всі обговорення, Issues, Pull Requests та інші форми взаємодії, пов'язані з проєктом.

Метою кодексу є підтримання безпечного, професійного та взаємоповажного середовища для всіх учасників.
