# Contributing to TrustVault

Дякуємо за інтерес до проєкту TrustVault: Loan Calculator.

## Як зробити внесок

### 1. Створення копії репозиторію

Зробіть Fork репозиторію та клонуйте його локально:

```bash
git clone https://github.com/voroniukdsipz24-ui/course-work.git
cd course-work
```

### 2. Створення окремої гілки

Для кожної зміни створюйте окрему гілку:

```bash
git checkout -b feature/my-change
```

Назва гілки повинна коротко описувати внесені зміни.

Приклади:

```text
feature/add-validation
fix/payment-calculation
docs/update-readme
```

### 3. Внесення змін

Перед внесенням змін встановіть необхідні залежності:

```bash
pip install -r requirements.txt
```

Зміни повинні відповідати поточній структурі та стилю проєкту.

### 4. Тестування

Перед створенням Pull Request необхідно запустити тести:

```bash
pytest -v
```

Також можна перевірити покриття:

```bash
pytest -v --cov=. --cov-report=term-missing
```

Нові функції бажано доповнювати відповідними тестами.

### 5. Commit

Commit повинен коротко описувати виконану зміну.

Приклад:

```bash
git add .
git commit -m "Add input validation"
```

### 6. Pull Request

Після завершення роботи:

```bash
git push origin feature/my-change
```

Після цього створіть Pull Request у GitHub.

У Pull Request необхідно:

* коротко описати внесені зміни;
* вказати, що саме було виправлено або додано;
* зазначити результати тестування;
* за потреби додати скріншоти.

### Правила

* Не додавайте до репозиторію паролі, токени та інші конфіденційні дані.
* Не змінюйте основну логіку без необхідності.
* Перевіряйте код перед створенням Pull Request.
* Нові функції повинні мати відповідне тестування.
* Пишіть зрозумілі commit-повідомлення.
